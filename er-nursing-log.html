근무 월
입력한 내용은 이 컴퓨터(브라우저)에만 자동 저장돼요. 다른 컴퓨터로 옮길 때는 맨 아래 백업 파일 저장 / 불러오기를 쓰세요. 환자 개인정보는 입력하지 않아요(숫자만).

간호사

의사

코드(er16 등)와 이름. 통계표에는 "코드 성"으로, 일지에는 이름으로 나와요.

한 번에 붙여넣기

이름을 한 줄에 하나씩(또는 쉼표로) 붙여넣으면 명단에 추가돼요. 의사는 er16 하길동처럼 코드와 이름을 띄어 쓰세요.

근무표

칸을 누를 때마다 바뀌어요. 간호사: 빈칸 → D → E → N → S(헤드널스), 의사: 빈칸 → D → N → DN(24시간). 칸을 누른 뒤 키보드 D·E·N·S 입력, Delete로 지우기, 방향키로 이동도 돼요.

DENDNS S = 헤드널스 → 일지 D칸 맨 앞에 "이름(S)"로 들어가요

엑셀 근무표 붙여넣기

엑셀 근무표에서 이름 칸부터 마지막 날짜 칸까지 행을 복사해 붙여넣으세요. 한 행 = 이름, 1일, 2일, … 순서. D/E/N/S 외의 글자(Off, 휴 등)는 빈칸으로 처리돼요. 명단에 없는 이름은 아래 선택한 직종으로 추가돼요.
